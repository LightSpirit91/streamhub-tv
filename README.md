# StreamHub TV

A cinema-style live TV app for every screen: Samsung TV (via Fire TV Stick), iPhone, iPad, Mac, Android and any browser. Sports, American networks, Latin America, Russian and Israeli channels, cinema and wildlife, organized into hubs.

Built with Expo SDK 58, `react-native-tvos`, `expo-video` and TypeScript.

- Architecture, channel coverage, Samsung TV setup and roadmap: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Run tests: `npm test`
- Build the channel catalog locally: `npm run doctor`
